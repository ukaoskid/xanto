Install correctly

Keep the device together.

  1. 01

    Download the ZIP

    Use the download on this page instead of saving an individual AMXD from GitHub.

  2. 02

    Extract the folder

    Keep the AMXD and every included engine or voice file in the same folder.

  3. 03

    Add it to Places

    Add the extracted folder to Live's Browser under Places, then load the device from there.

XOrds is MIDI-only. Put it before an instrument on the same MIDI track; it generates notes rather than sound.
